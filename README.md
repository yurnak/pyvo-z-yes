# Пиво з ЄС напряму

Інструкція: як заклад у Польщі може купувати пиво безпосередньо в броварні
з іншої країни ЄС — статус `uprawniony odbiorca`, документ e-SAD, акциз
і забезпечення.

Сторінка: https://yurnak.github.io/pyvo-z-yes/

Один статичний файл `index.html`, без залежностей крім Google Fonts.
Містить калькулятор акцизу (гектолітри × °Plato × 11,47 zł) і готові
тексти запитів до постачальника та urzędu skarbowego.

Підготовлено за офіційними джерелами PUESC, podatki.gov.pl і biznes.gov.pl
станом на вересень 2026 р. Не є податковою консультацією.
